# Genesis × 強化学習で四足ロボット Go2 にバク転を覚えさせる

物理シミュレータ [Genesis](https://github.com/Genesis-Embodied-AI/Genesis) と強化学習（PPO）を使い、四足ロボット Unitree Go2 にバク転を学習させました。
Genesis には Go2 のバク転の学習済みモデルは入っていますが、**学習コードは公開されていない**ため、報酬関数と学習スクリプトを自作しています。
ローカルに環境を作らず、**Google Colab（T4 GPU）だけで**学習から動画作成まで完結させています。

## 結果

| | 学習回数 | 学習時間（T4） | 結果 |
|---|---|---|---|
| 歩行（公式サンプル） | 300 回 | 約 4 分 | 20 秒間転ばずに歩けるようになった |
| バク転 v1（報酬の初期設計） | 5001 回 | 約 1 時間 | 1/4 回転して元に戻る動きに収束し、失敗 |
| **バク転 v2（報酬を改善）** | 5001 回 | 約 1 時間 8 分 | **200 回目で 1 回転に成功**。その後、着地も安定 |

バク転 v2 の学習の過程（動画で確認した様子）:

| 学習回数 | 動き |
|---|---|
| 100 回目 | 半回転して転ぶ |
| 200 回目 | 1 回転できたが、着地した後に震える |
| それ以降 | 震えはなくなったが、姿勢が少し不自然 |

学習ログから見た経過（回転量・着地の報酬が、それぞれの満点に対して何 % もらえているか。ログの値から換算した推定値）:

| 学習回数 | 回転量の報酬 | 着地の報酬 | 平均報酬 |
|---|---|---|---|
| 0 | 1 % | 0 % | -0.25 |
| 100 | 46 % | 0 % | 7.0 |
| 200 | 95 % | 50 % | 10.8 |
| 1000 | 89 % | 62 % | 13.2 |
| 2000 | 99 % | 97 % | 19.1 |
| 5000 | 99 % | 98 % | 20.7 |

> 換算方法: 回転量の報酬は「回った角度 ÷ 360 度」で最大 1、着地の報酬は 1 回転しきったときだけもらえるので、ログの値をそれぞれの理論上の最大値で割っています。

## 環境

- Google Colab（Tesla T4、High-RAM）。VS Code の Colab 拡張から接続
- Python 3.13
- `genesis-world` 1.4.5
- `rsl-rl-lib` 5 系（PPO の実装）
- 並列環境数 4096（GPU 上で 4096 台の Go2 を同時にシミュレーション）

## Colab で環境を作るときに詰まった点

参考にした記事（[Genesis を Google Colab で試す](https://tototototototo7.hatenablog.com/entry/2025/genesis_test_google_colab)）は古い Genesis（0.2 系）が前提だったため、最新版（1.4.5）では以下の対応が必要でした。

| 症状 | 原因 | 対処 |
|---|---|---|
| `Please install 'rsl-rl-lib>=5.0.0'` | Genesis 1.4.5 のサンプルは rsl_rl 5 系が必要（記事は v1.0.2） | `go2_train.py` から必要なバージョンを読み取ってインストール |
| `unrecognized arguments: -B ... --max_iterations` | 学習スクリプトのオプション名が変わっていた | `-b` と `--max-iterations` に変更 |
| エラー表示なしで学習が終了（`Segmentation fault`） | Colab に EGL（画面のない環境での描画）用の NVIDIA の設定ファイルがない | `/usr/share/glvnd/egl_vendor.d/10_nvidia.json` を作成（MuJoCo の公式 Colab チュートリアルと同じ対処） |
| 録画で `stop_recording() got an unexpected keyword argument` | 録画 API の変更（保存先と fps は `start_recording()` で指定し、フレームは自動で記録される） | 新しい API に合わせて修正 |

記事では Colab での描画が 1 フレームに約 10 分かかったとありますが、EGL の設定で GPU 描画ができるようになり、Colab 上で動画を作れるようになりました。

## バク転の学習の仕組み

### 環境

公式の `go2_backflip.py`（学習済みモデルを動かすためのスクリプト）の設定を流用しています。

- 1 エピソード 2 秒
- 体が傾いてもエピソードを打ち切らない
- 観測（60 次元）に「エピソード内の経過時間」を含める。ロボットが「今は踏み切りの時間」「今は回転の時間」と判断できるようにするため
- 歩行と違い、エピソードは毎回最初（踏み切りの前）から始める

### 報酬の設計（v2）

エピソードを時間で区切り、段階ごとに違う動きを評価します。

| 時間 | 段階 | 報酬 | 重み |
|---|---|---|---|
| 0.4〜0.8 秒 | 踏み切り | 上向きの速さ（`jump`） | 2.0 |
| 0.5〜1.1 秒 | 空中で回転 | 後ろ向きに回転する速さ（`ang_vel_y`） | 1.0 |
| 0.5〜1.1 秒 | 空中で回転 | 胴体が立ち姿勢より高いほど（`flight_height`） | 5.0 |
| 1.1 秒〜 | 回転後 | 回った角度の合計が 1 回転に近いほど（`flip_rotation`） | 3.0 |
| 1.3 秒〜 | 着地 | 立ち姿勢の高さに近いほど（`landing_height`）。**1 回転しきった場合だけ** | 2.0 |
| 全体 | | その時刻の目標の姿勢に近いほど（`orientation_tracking`）。回転後は **1 回転しきった場合だけ** | 5.0 |
| 全体 | | 横回転・ひねり（`ang_vel_xz`）、関節の速すぎる動き（`dof_vel`）、急な動作の変化（`action_rate`）へのペナルティ | -0.1 / -0.0001 / -0.01 |

- 回った角度は、胴体が 0.25 m 以上の高さにあるときだけ数える（地面の上で転がるでんぐり返しを数えないため）
- 回った角度の合計が 306 度（1.7π）以上なら「1 回転しきった」とみなす

### v1 から v2 への改善

v1 では 5001 回学習しても、**1/4 回転して元に戻る**動きに落ち着いてしまいました。

v1 の報酬では、回りきれずに元の姿勢に戻っても、着地の報酬（まっすぐ立つ・立ち姿勢の高さ）が満点でもらえました。1 回転に挑戦して転ぶより「少し回って戻る」ほうが確実に点数を稼げるため、ロボットはそちらを選んでいました。また、回った角度や跳んだ高さを直接は評価しておらず、「惜しかった」ことが報酬に表れませんでした。

v2 では次の 3 点を変えました。

1. **1 回転しきったときだけ、着地の報酬を与える**（元に戻るだけでは得をしない）
2. **回った角度の合計が 1 回転に近いほど報酬を与える**（回りきれなくても、前より多く回れたことが評価される）
3. **空中で胴体が高いほど報酬を与える**（回転に必要な滞空時間を稼ぐ）

その結果、200 回目のモデルで 1 回転できるようになりました。

### 今後の課題

- 着地後の姿勢が少し不自然。足の接地や関節の姿勢を評価する報酬を加えると改善しそう
- 回転のタイミング（0.5 秒から 0.6 秒で 1 回転）は仮の値。お手本のモデルの動きを測って合わせると、より自然になりそう

## 再現手順

1. `pai_finalwork.ipynb` を Google Colab で開き、ランタイムを **T4 GPU** にする
2. 1 章（インストール、EGL の設定）と 2 章（Google Drive。保存しない場合は `USE_DRIVE = False`）を実行する
3. 5 章の `%%writefile` の 3 つのセルを実行して、バク転用のスクリプトを作る
4. 5-1 で、公式の学習済みモデル（お手本）の動画を確認する
5. 5-2 で学習する（`BF_MAX_ITER = 5001` で約 1 時間）
6. 5-3 で動画を作る。まとめて録画するセルでは、100 回ごとのモデルの動画を作って学習の過程を見比べられる

3 章・4 章は歩行の学習と評価で、バク転だけなら実行しなくてかまいません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `pai_finalwork.ipynb` | すべてのコード。以下のスクリプトはノートブックの `%%writefile` のセルから Colab 上に作られる |
| （生成）`go2_backflip_env.py` | バク転用の環境と報酬 |
| （生成）`go2_backflip_train.py` | 学習スクリプト |
| （生成）`go2_backflip_record.py` | 動画作成スクリプト（お手本、指定したモデル、複数のモデルをまとめて） |

Genesis のリポジトリにある `go2_env.py`・`go2_train.py`・`go2_backflip.py` は書き換えず、読み込んで使っています。
